# 云杉智能客服平台使用手册

版本：v1.3  
更新时间：2026-06-01  
适用对象：客服主管、客服专员、系统管理员

---

## 1. 产品简介

云杉智能客服平台是一套面向中小型电商公司的 AI 客服系统，主要用于自动回复用户咨询、管理客服工单、分析客户满意度，并支持人工客服接管。

平台包含四个核心模块：

1. 智能问答机器人
2. 工单管理系统
3. 客服数据看板
4. 权限与团队管理

智能问答机器人主要负责处理常见问题，例如物流查询、退换货规则、优惠券使用、订单状态查询等。

---

## 2. 用户角色说明

平台中共有三种默认角色：

| 角色       | 权限范围                                   | 适合人群               |
| ---------- | ------------------------------------------ | ---------------------- |
| 系统管理员 | 可管理所有团队、成员、知识库和系统设置     | 技术负责人或运营负责人 |
| 客服主管   | 可查看团队数据、分配工单、编辑知识库       | 客服团队负责人         |
| 客服专员   | 可处理工单、接管机器人会话、查看自己的数据 | 一线客服人员           |

客服专员不能删除知识库内容，也不能修改团队成员权限。

客服主管可以编辑知识库，但不能修改系统级 API 配置。

---

## 3. 智能问答机器人

智能问答机器人会优先从企业知识库中检索相关内容，然后生成回答。

机器人回答流程如下：

1. 接收用户问题
2. 判断问题意图
3. 从知识库中检索相关片段
4. 生成候选回答
5. 判断是否需要人工接管
6. 返回最终回答

如果机器人的置信度低于 0.65，系统会自动建议转人工。

如果用户连续追问超过 3 次，系统也会建议转人工。

---

## 4. 知识库管理

知识库支持上传以下格式的文件：

- Markdown
- PDF
- Word 文档
- 纯文本文件
- CSV 表格

单个文件最大支持 20MB。

一个知识库最多可以包含 500 个文档。

推荐将长文档按照主题拆分，例如：

- 售后政策
- 物流规则
- 会员权益
- 优惠券说明
- 常见故障处理

知识库更新后，系统会自动重新生成向量索引。通常情况下，索引更新时间在 1 到 5 分钟之间。

---

## 5. 工单管理

当机器人无法解决问题时，会创建人工工单。

工单共有五种状态：

| 状态         | 含义                         |
| ------------ | ---------------------------- |
| 待处理       | 工单已创建，但尚未分配客服   |
| 处理中       | 客服已经接手，正在处理       |
| 等待用户回复 | 客服已回复，等待用户补充信息 |
| 已解决       | 问题已经处理完成             |
| 已关闭       | 工单结束，不再处理           |

客服主管可以手动分配工单。

如果工单超过 24 小时未处理，系统会自动标记为“超时”。

## 6. 客服数据看板

数据看板提供以下指标：

- 今日会话数
- 机器人解决率
- 人工接管率
- 平均首次响应时间
- 平均工单处理时长
- 用户满意度评分

其中，机器人解决率的计算方式为：

机器人解决率 = 机器人独立完成的会话数 / 总会话数

如果某个用户在会话中转人工，则该会话不计入机器人独立完成。

## 8. API 限制

专业版和企业版可以使用开放 API。

专业版 API 限制如下：

- 每分钟最多 120 次请求
- 每天最多 100,000 次请求
- 单次请求最大 8KB
- 超过限制后返回 429 状态码

企业版可以根据合同调整 API 限制。

如果 API Key 泄露，系统管理员应立即在后台禁用旧 Key，并生成新的 Key。

## 9. 常见问题

### 9.1 为什么机器人回答不准确？

可能原因包括：

1. 知识库内容过旧
2. 用户问题表达不清楚
3. 文档切分粒度过大
4. 检索结果与问题不相关
5. 相似问题在知识库中存在冲突答案

建议先检查知识库内容是否最新，再查看召回片段是否正确。

### 9.2 为什么上传文档后不能马上搜索到？

上传文档后，系统需要进行解析、切分、向量化和索引构建。

通常 1 到 5 分钟后可以搜索到新内容。

如果超过 10 分钟仍无法搜索，建议检查文档格式是否受支持。

### 9.3 客服专员可以修改知识库吗？

不可以。

客服专员只能查看与工单相关的知识库内容，不能新增、编辑或删除知识库文档。

只有客服主管和系统管理员可以编辑知识库。

### 9.4 企业版和专业版的主要区别是什么？

企业版支持私有化部署、无限知识库、无限机器人会话数、专属模型配置和高级安全审计。

专业版支持 API 接入，但不支持私有化部署。

## 10. 故障处理

### 10.1 API 返回 429

429 表示请求频率超过限制。

处理方式：

1. 降低请求频率
2. 增加重试间隔
3. 使用指数退避策略
4. 联系客户经理升级套餐

### 10.2 机器人频繁转人工

可能原因：

- 知识库覆盖不足
- 问题分类不准确
- 置信度阈值设置过高
- 用户问题本身需要人工判断

可以先查看最近 100 条转人工会话，分析高频问题，再补充知识库。

### 10.3 知识库索引失败

常见原因：

- 文件超过 20MB
- 文件格式不支持
- PDF 内容为扫描图片，无法直接解析文本
- 文档中存在大量乱码

建议将文档转换为 Markdown 或纯文本后重新上传。

## 11. 安全建议

系统管理员应定期检查成员权限。

离职员工账号应在 24 小时内停用。

API Key 不应写在前端代码中，也不应提交到 Git 仓库。

建议每 90 天轮换一次 API Key。
